# תרגול מבחני Java – מבוא למדעי המחשב (11203)

אתר תרגול לחמישה מבחנים בקורס "מבוא למדעי המחשב ושפת Java א":

- בחינת גמר – מועד א 19.10.2026
- מבחן מסכם 01 ו-02 (11203)
- מבחן דוגמה 01 ו-02

בכל סעיף יש תיבה לכתיבת התשובה ב-Java וכפתור **בדוק**. הקוד מקומפל ומורץ **בדפדפן עצמו**, בלי שרת, מול סדרת בדיקות של הסעיף, והתלמיד רואה אילו בדיקות עברו ואילו לא (כולל שגיאות קומפילציה עם מספר שורה). שאלות מעקב קוד ("מה יודפס?") נבדקות ישירות. לכל סעיף יש גם פתרון לדוגמה.

## איך הבדיקה עובדת

- ב-Java רץ [CheerpJ](https://cheerpj.com/) – JVM של OpenJDK 8 ב-WebAssembly, שנטען מהשרת של Leaning Technologies.
- הקומפיילר הוא `javac` מתוך `lib/tools.jar` של OpenJDK 8 (GPL v2 עם Classpath Exception).
- `harness.js` עוטף את קוד התלמיד בקובץ Java אחד יחד עם קוד העזר של השאלה (מחלקות נתונות, שיטות מסעיפים קודמים) ועם הבדיקות. לולאות בקוד התלמיד מקבלות מונה, כך שלולאה אינסופית נעצרת עם הודעה.
- בשאלות "טסטר" קוד התלמיד מורץ גם מול מחלקות תקינות (צריך להדפיס Pass) וגם מול מחלקות עם באג (הבדיקה המתאימה צריכה להיכשל).
- ההרצה הראשונה טוענת את מנוע ה-Java ולוקחת בערך חצי דקה; ההרצות הבאות מהירות יותר.
- ההתקדמות והקוד נשמרים ב-`localStorage` של הדפדפן.

## מבנה

| קובץ | תפקיד |
| --- | --- |
| `index.html`, `app.js`, `style.css` | הממשק |
| `data/exam-*.js` | השאלות, קוד התחלתי, פתרונות ובדיקות לכל מבחן |
| `harness.js` | בניית קובץ ה-Java לבדיקה ופענוח התוצאות |
| `runner.js` | טעינת CheerpJ, קומפילציה והרצה |
| `checks.js` | בדיקת שאלות טקסט |
| `test/run.js` | מוודא שכל פתרון לדוגמה עובר את כל הבדיקות (דורש JDK מקומי) |
| `test/e2e.js` | בדיקת קצה-לקצה בדפדפן עם Playwright |

```sh
node test/run.js      # כל הפתרונות עוברים, והקוד ההתחלתי לא
node test/e2e.js      # בדיקת הממשק
```

## משתמשים (Firebase)

הרשמה והתחברות עם אימייל וסיסמה או עם חשבון Google, ושני סוגי משתמשים: תלמיד ומורה. משתמש שנכנס עם Google בפעם הראשונה בוחר שם וסוג משתמש. (ב-Firebase: Authentication → Sign-in method → להפעיל Email/Password ו-Google.)

- `firebase-config.js` – הגדרות הפרויקט ב-Firebase (`firebaseConfig`).
- `auth.js` – התחברות, הרשמה, שמירת ההתקדמות ב-Firestore (`progress/{uid}`) ורשימת התלמידים למורה.
- `firestore.rules` – כללי האבטחה. מעתיקים ל-Firestore → Rules ומפרסמים.
- הרשמה כמורה אפשרית רק לאימייל שמופיע באוסף `teacherEmails` (מסמך שה-ID שלו הוא האימייל באותיות קטנות). את המסמכים מוסיפים ידנית ב-Firebase Console.
- מורה רואה ב"דף מורה" את כל התלמידים ואת ההתקדמות שלהם בכל מבחן ותרגול.
- כל לחיצה של תלמיד מחובר על **בדוק** או **הצג פתרון** נשמרת באוסף `attempts`: הסעיף, הזמן, אם התשובה נכונה, השגיאות (קומפילציה או בדיקות שנכשלו) והקוד שנשלח. לחיצה על שם התלמיד בדף המורה פותחת את היומן שלו, עם סינון לפי מבחן ולפי תשובות לא נכונות. התלמיד יכול רק להוסיף רשומות משלו, לא לשנות או למחוק.
